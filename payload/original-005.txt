  <p class="lead">Cas d’usage : une modification de l’API a cassé le parcours de paiement dans le front-end. Le projet comprend un dépôt front, un dépôt API et un dépôt de tests end-to-end.</p>

    <div class="step">Demander d’abord une analyse sans modification : reproduction, hypothèses, fichiers impliqués et plan de test.</div>
    <div class="step">Valider le plan, puis autoriser les modifications dans une branche ou un worktree isolé.</div>
